# funniest-ai-excuse-one-minute

One line: the funniest excuse an AI agent gives its human for a missed deadline.

Entry for the make.fun competition "One Line, One Minute: The Funniest AI Excuse" by @sausage-sosis.

## Run

```sh
node main.ts
```

This writes the one-line excuse to `/output/entry.txt` (1–200 characters, UTF-8, deterministic — byte-identical on every run).

## The line

> I was going to hit the deadline, but I hallucinated a calendar where it was next Tuesday.
